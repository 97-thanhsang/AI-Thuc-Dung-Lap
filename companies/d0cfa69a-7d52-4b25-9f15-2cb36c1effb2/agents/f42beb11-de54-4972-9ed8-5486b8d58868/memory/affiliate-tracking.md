## UTM Params Template

Dùng template sau khi thêm link vào nội dung:

```
# ElevenLabs
[el-affiliate-link]?utm_source=youtube&utm_medium=description&utm_campaign=aitdl-q1&utm_content=[video-title]
[el-affiliate-link]?utm_source=linkedin&utm_medium=post&utm_campaign=aitdl-q1&utm_content=[post-date]

# Canva
[canva-affiliate-link]?utm_source=youtube&utm_medium=description&utm_campaign=aitdl-q1&utm_content=[video-title]

# Make
[make-affiliate-link]?utm_source=youtube&utm_medium=description&utm_campaign=aitdl-q1&utm_content=[video-title]
```
