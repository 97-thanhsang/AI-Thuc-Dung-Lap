## Quy Tắc Sử Dụng Affiliate Links

1. **Luôn disclosure**: "Link có hoa hồng - nhưng tôi chỉ recommend tool tôi thực sự dùng"
2. **Không spam**: Affiliate promo = 5% content ratio (theo content pillar)
3. **UTM tracking**: Thêm UTM params để track per-platform
4. **Honest review**: Đề cập cả ưu lẫn nhược điểm

**UTM Template**:
```
[affiliate-link]?utm_source=[platform]&utm_medium=content&utm_campaign=aitdl&utm_content=[content-title]
```
